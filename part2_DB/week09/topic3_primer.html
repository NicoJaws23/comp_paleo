Database Components

The database is comprised of 3 essential parts

Observer Samples: Each day an observer creates an observer sample which serves as the parent record for all data collected that day

Avistajes: Any time an observer sees a primate species, they record an avistaje record which indicates the species seen, the group (if known), the behavior when seen, and the time of the sighting

Focal Samples: Any time an observer collects focal data on a single individual, they store the data in a focal sample
