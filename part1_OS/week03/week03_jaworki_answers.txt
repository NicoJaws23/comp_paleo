Answer:
This piped command line fist uses the tail command to start printing information at line 2 of the file, ignoring the header columns. awk -F '\t' specifies that the columns in the file are tab-delimited. Then {count[$22]++} END goes through the scientific_name column and counts how many each record is present for each scientific name. {for (name in count) print count[name], name}' then established a for loop to display the count of each taxa next to its name. Finally, sort -rn displays the counts in descending order.
The five taxa in the dataset based on genus and species are Australopithecus anamensis (242), Paranthropus boisei (205), Homo erectus (154), Homo habilis (100), and Paranthropus aethiopicus (66). There are also 2 specimens of Kenyanthropus platyops.
