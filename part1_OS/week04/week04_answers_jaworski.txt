# Check for rows with wrong column count
BAD_ROWS=$(awk -F'\t' -v cols="$EXPECTED_COLS" 'NF != cols {print NR}' "$FILEPATH" | wc -l | tr -d ' ')
if [ "$BAD_ROWS" -eq 0 ]; then
    echo "PASS: all rows have $EXPECTED_COLS columns"
else
    echo "FAIL: $BAD_ROWS row(s) have wrong column count"
    awk -F'\t' -v cols="$EXPECTED_COLS" \
        'NF != cols {print "      First offending row: file=" FILENAME ", line=" NR " (" NF " columns)"; exit}' \
        "$FILEPATH"
    echo "      First 5 offending line numbers:"
    awk -F'\t' -v cols="$EXPECTED_COLS" 'NF != cols {print " Line", NR, "has", NF, "columns"}' \
        "$FILEPATH" | head -5
    ERRORS=$((ERRORS + 1))
fi

3.3
1. IFS=$'\t' read -r CATALOG_NUMR REST assigns the first column in a TSV
file to CATALOT_NUM and every other column to REST while the loop is
going. IFS is the internal field separator in the shell and controls
what read treats as a delimiter. Since this file is tab delimited, it is
set '\t'.
2. [[ "$CATALOG_NUM" != "$PREFIX"* ]] checks if the catalog number does
not start with the specified prefix. This line uses globbing with the *
to say look for anything that starts with th prefix. Globbing requires
the use of [[ ]], so [ ] would not have interpreted the * correctly
3. tee -a "$LOG_FILE" takes the unexpected catalog numbers found by the
while loop and appends then to the bad_catalog_numbers.log file. tee 
differs from simple redirection in that tee will both display stdout and
write it to a file.

Part 5 Question Responses
1. In python, variables are simply assigned using an = surrounded or not 
surrounded by spaces. Variables in python can be called just by typing
the variable name into a command. In bash, variables are assigned with an 
= with no spaces around it. Variables in bash may also need ""s, ()s, or 
a $ with then at assignment depending on if they are simple values or
regular expressions. Additionally, in bash when you call a variable it 
must be have $ as its prefix.  
 
2. For loops in python are simpler in my opinion. While bash requires 
;do before starting the loop, python can simply take for X in Y and then 
run the loop

3. In python, indentation is how blocks of code are defined. For example, 
a for loop within a for loop would need to be indented to be nested in
the loop and run properly. In bash, indentation is used more to make 
long portions of scripts more readable. However, in bash we need to use
\ at the end of a given line before indentation to tell bash that the
indented line in continuous.

4. for i, row in enumerate(reader) looks at every row individually, to 
loop through and clean each row. There are 2 variables (i and row) 
because they are needed by the enumerate(reader) portion to keep track of 
which row the function is on. i indexes the row while row holds the data 
in that row.

5. This function captures arguments with the sys.argv tool. This took is 
called from the sys module imported with import sys. The validation check 
in line 43 expects 3 arguments because the sys.argv is communicating 
between bash and python. So it needs the specific code to use 
(fix_newlines.py), the input argument (input.csv), and the output argument
